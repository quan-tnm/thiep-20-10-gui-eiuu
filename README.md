# Thiệp 20/10 — Tini từ Miqi (bản sửa)

## Quan trọng khi upload
Mở ZIP và tải **các file bên trong thư mục `thiep-20-10-tini-fixed`** lên repository, không tải nguyên thư mục bọc bên ngoài. `index.html` phải nằm ngay ở gốc repository.

## Cấu trúc cần có trên GitHub
- `index.html`
- `style.css`
- `script.js`
- `assets/images/ky-niem-01.jpg` đến `ky-niem-12.jpg`
- `assets/music/nhac-nen.mp3` (bản MP3 giữ làm dự phòng; nhạc chính dùng YouTube embed)

## Âm nhạc
Trang phát file MP3 `assets/music/nhac-nen.mp3` đã được đóng gói sẵn. Nhấn nút “Bật nhạc” sau khi trang tải. Có thêm liên kết mở bài hát trên YouTube nếu trình duyệt không phát file MP3.

## Triển khai
1. Tạo repository GitHub.
2. Upload `index.html`, `style.css`, `script.js` và thư mục `assets` vào gốc repository.
3. Settings → Pages → Deploy from a branch → branch `main` → folder `/(root)` → Save.
4. Mở URL GitHub Pages sau khi deploy hoàn tất.

Nếu ảnh vẫn không hiện, vào repository kiểm tra có đúng đường dẫn `assets/images/ky-niem-01.jpg` hay không. Tên file phân biệt chữ hoa/chữ thường.
